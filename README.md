# HiCo Thermal

Automatic thermal unlock for games, part of the Flux ecosystem. **Private software**: this
repository is the public release channel; the source code is not published.

- **Download:** [latest release](https://github.com/FebriCahyaa/HiCo-Release/releases/latest):
  `*-arm64.zip` for 64-bit ROMs (including 64-bit-only AOSP ROMs), `*-arm.zip` for
  32-bit ROMs, `*-universal.zip` works on both. Not sure? Take the universal zip; the
  installer refuses a zip that does not match the ROM.
- **ROMs:** MIUI, HyperOS, LineageOS and other AOSP-based ROMs
- **Requires:** [Flux Tweaks](https://github.com/FebriCahyaa/Flux/releases) v1.2.0 or newer,
  root (Magisk, KernelSU or APatch), Android 9+
- **Updates:** installed modules are notified by the root manager through `update.json`
- **License:** [EULA](EULA.md) (English / Bahasa Indonesia), accepted when installing;
  third-party notices in [NOTICE.md](NOTICE.md)
- **Changes:** [changelog.md](changelog.md)
